Playback & Formats

  • ✓ High-quality audio playback (MP3, FLAC, AAC, M4V, OGG, WAV, etc.)
  • ✓ Direct video clip playback support
  • ✓ Open and play audio archives directly from ZIP files
  • ✓ Support for running multiple instances simultaneously

Playlist & Library Management

  • ✓ JSON-backed state management
  • ✓ Save and load standard M3U playlists
  • ✓ Export playlists directly to CSV and JSON formats
  • ✓ Search by metadata & filenames to generate instant new playlists

Metadata & Lyrics Tools

  • ✓ Edit audio metadata tags & album art covers
  • ✓ Embed and view synchronized or plain lyrics
  • ✓ Batch rename media files based on metadata tags
  • ✓ Safe local file management operations

Design & Experience

  • ✓ Clean, user-friendly UI/UX designed for fast interactions
