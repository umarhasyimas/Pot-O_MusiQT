What's new in 2.8.2 "Verse"

QGroupBox

A big step up from 2.7.5, with a reworked playback engine built around BASS mixer streams.

Crossfade & Gapless
🔀

Smooth crossfade between tracks with its own menu, plus gapless playback that pre-loads the next song.

Volume Normalization
📏

ReplayGain-style analysis cached to disk, with a selectable target level and a command to clear the cache.

8, 10 & 15-band EQ
🎛

Three equalizer layouts, presets, save and load, plus automatic preset selection per track by genre or audio fingerprint.

Favorites
★

Per-track favorite button, a Favorites tab that always stays first, and a quick Favorite button on Now Playing.

Watch Folders
📁

Auto-sync folders into your playlists, with background missing-track detection that never blocks the UI.

Themes & Mini Player
🎨

Live theme switching with Default, Midnight and Aurora, drop-in JSON themes, and a small Winamp-style mini player.

Powered by BASS

Low-latency, rock-solid playback built around BASS mixer streams (BASSmix) for smooth transitions.

MP3WAVOGGFLACM4AAAC
  • ✓Gapless playback pre-loads the next track for zero silence between songs
  • ✓Crossfade between tracks, with a dedicated Crossfade menu
  • ✓Volume normalization with cached analysis and a selectable target level
  • ✓Pitch control from -12 to +12 semitones in 0.5 steps
  • ✓Playback speed 0.5×, 0.75×, 1.0×, 1.25×, 1.5×, 2.0×
  • ✓Balance and Pre-amp mini-sliders (double-click to reset)
  • ✓Output device selection — switch headphones, speakers or DAC live, with automatic device recovery
  • ✓Stereo / Left / Right routing plus Channel Mapping (BASSmix)
  • ✓A-B Repeat, shuffle with history-aware previous, and Repeat Off / One / All
  • ✓Sleep timer: by minutes, at a clock time, or after N tracks

Shape your sound

Real-time equalizer with presets that follow your music, and a live spectrum visualizer.

  • ✓8-band, 10-band and 15-band layouts with real-time sliders
  • ✓Built-in presets (Rock, Pop, Classical, Bass Boost and more) in grouped categories
  • ✓Equalizer popup window, Save Preset… / Load Preset… to files, and one-click Reset to Default
  • ✓Automatic preset selection per track by genre or audio fingerprint, with manual override
  • ✓EQ state saved and restored between sessions
  • ✓FFT spectrum visualizer with animated bars, NumPy-accelerated when available, toggled without interrupting playback

Your library, organised

Tabbed playlists stored in SQLite, with watch folders and fast search.

  • ✓Unlimited tabbed playlists — create, rename, delete and reorder; drag and drop files and folders
  • ✓Favorites tab that always stays first
  • ✓Watch Folders (Auto-Sync) with on/off toggle and missing-track detection
  • ✓Import Folder with subfolders, or one tab per folder; load a folder or a ZIP archive (password supported)
  • ✓Import and export M3U; export track data as CSV or JSON
  • ✓Undo / Redo for playlist actions, automatic database backup and periodic autosave
  • ✓Per-playlist shuffle and repeat settings
  • ✓Real-time and global search across title, artist and album, with flexible sorting

Tags, covers and lyrics

Edit everything without leaving the player.

  • ✓Embedded album art display with folder-cover fallback, and a full-size cover viewer with save and replace
  • ✓Embed custom cover art into tags (MP3, FLAC)
  • ✓Track Properties editor for title, artist, album, year, genre and track number
  • ✓Rename files from metadata; view bitrate, sample rate, duration, size and codec
  • ✓Plain-text lyrics with adjustable font size, auto-scroll and overlay mode on the album art
  • ✓Embed lyrics into tags (ID3 for MP3, FLAC metadata) and edit them in-app

Make it yours

Switch themes live or drop in your own JSON palette.

  • ✓Custom themes as drop-in JSON in palettes/, with a template included

  • ✓Responsive layout from compact to wide, and a floating playlist overlay mode

At home on Windows

Native taskbar controls and a session that picks up where you left off.

  • ✓Taskbar thumbnail toolbar with Play, Pause, Previous and Next, plus a taskbar progress bar
  • ✓Single instance — opening files sends them to the running window
  • ✓Open files from the command line, or use Open Disc for removable and optical drives
  • ✓App data kept in %APPDATA%\PotOMusiQT\, safe to install in Program Files
  • ✓Session restore: last track, position, volume, EQ, speed and playlist state
  • ✓Export / Import Settings and Reset Playback Preferences
